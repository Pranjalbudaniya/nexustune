## 2. API Surface Audit

### 2.1 Search & Filters
- **Service**: `ServiceList.YouTube`
- **Search Query**: `SearchExtractor` supports YouTube Music filters:
  - `songs` (tracks)
  - `albums`
  - `artists`
  - `playlists`
  - `videos`
- **Search Suggestions**: `YouTubeSuggestionExtractor` returns instant query completion strings based on user prefix input.

### 2.2 Stream Resolution & Metadata
- **Extractor**: `StreamInfo.getInfo(service, urlOrId)`
- **Audio Streams**: Exposes `AudioStream` list with:
  - Format: Opus (WebM) and AAC (M4A)
  - Bitrate: 128 kbps, 160 kbps, 256 kbps (when available)
  - Delivery: Direct HTTPS URL
- **Lifecycle & Expiry**:
  - Stream URLs generated by YouTube expire typically within 4 to 6 hours (URL parameters include `&expire=...`).
  - **Rule**: Never persist stream URLs in Room or DataStore. Persist only stable media IDs (`videoId`).
  - **Resolution**: Resolve stream URL at play time using Media3 `ResolvingDataSource` or an interceptor resolver.
  - **Cache**: In-memory LRU cache of resolved stream URLs with TTL (e.g. 3 hours). On HTTP 403 Forbidden or 410 Gone, invalidate cache entry and re-extract immediately.

### 2.3 Home Feed & Trending Content
- **Extractor Capability**: NewPipeExtractor provides `KioskList` (e.g. `Trending`), but YouTube Music's algorithmic personalized home feed is not accessible via unauthenticated extraction.
- **Architectural Decision**: NexusTune will construct the Home Screen from local and deterministic remote signals:
  1. Quick Picks (recently played tracks and their related streams)
  2. Favorites / Most Played (derived from Room database)
  3. YouTube Trending / Charts Kiosk (when available via `KioskExtractor`)
  4. Curated explore playlists (charts, genres)
  - Recorded in `docs/DECISIONS.md`.

## 3. OkHttp Downloader Implementation

NewPipeExtractor requires an implementation of `org.schabi.newpipe.extractor.downloader.Downloader`.
We implement `OkHttpDownloader` backed by a shared `OkHttpClient`:

```kotlin
class OkHttpDownloader(
    private val client: OkHttpClient,
    private val userAgent: String = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
) : Downloader() {
    override fun execute(request: Request): Response {
        val okHttpRequest = okhttp3.Request.Builder()
            .url(request.url())
            .method(request.httpMethod(), request.dataToSend()?.toRequestBody())
            .headers(request.headers().toOkHttpHeaders())
            .header("User-Agent", userAgent)
            .build()
            
        val okHttpResponse = client.newCall(okHttpRequest).execute()
        return Response(
            okHttpResponse.code,
            okHttpResponse.message,
            okHttpResponse.headers.toMultimap(),
            okHttpResponse.body?.string(),
            okHttpResponse.request.url.toString()
        )
    }
}
```

### Localization & Country Configuration
- Configured during initialization via `NewPipe.init(downloader, Localization(language, country))`.
- Exposed in Settings: User can select Preferred Content Country (ISO 3166-1 alpha-2) and UI Language.

## 4. Typed Error Model and Resilience

Extractor operations and streaming are vulnerable to network fluctuations, YouTube changes, and rate limits. NexusTune wraps all extractor operations in a typed result hierarchy:

```kotlin
sealed interface MusicResult<out T> {
    data class Success<T>(val data: T) : MusicResult<T>
    sealed interface Failure : MusicResult<Nothing> {
        val error: ExtractorError
    }
}

sealed class ExtractorError(
    open val message: String,
    open val cause: Throwable? = null,
    val canRetry: Boolean = false
) {
    data class NetworkError(override val cause: Throwable?) : ExtractorError("Network connection error", cause, canRetry = true)
    data class RateLimitedError(val retryAfterSeconds: Int? = null) : ExtractorError("Rate limited by service (429)", null, canRetry = true)
    data class GeoBlockedError(val country: String?) : ExtractorError("Content is unavailable in your region", null, canRetry = false)
    data class AgeRestrictedError(val videoId: String) : ExtractorError("Content is age restricted and cannot be streamed without login", null, canRetry = false)
    data class TrackRemovedError(val videoId: String) : ExtractorError("Track has been deleted or made private", null, canRetry = false)
    data class ExtractorBrokenError(override val cause: Throwable?) : ExtractorError("Extractor parsing failure; YouTube schema may have changed", cause, canRetry = false)
    data class UnknownError(override val message: String, override val cause: Throwable?) : ExtractorError(message, cause, canRetry = true)
}
```

### Retry Policy
- Exponential backoff with full jitter: `min(maxDelay, baseDelay * 2^attempt) * random(0.5, 1.5)`.
- Max retries: 3 attempts for `NetworkError` and `RateLimitedError`.
- For `ExtractorBrokenError`: UI directs user to the About/Settings screen displaying the pinned extractor version (`v0.27.1`) with a direct link to check for application updates.

## 5. R8 / ProGuard Keep Rules

NewPipeExtractor uses Rhino/Nashorn JavaScript execution, jsoup HTML parsing, and protobuf reflections. The following keep rules must be included in `:core:extractor` `consumer-rules.pro`:

```pro
# NewPipeExtractor core rules
-keep class org.schabi.newpipe.extractor.** { *; }
-keep interface org.schabi.newpipe.extractor.** { *; }

# Rhino JS Engine rules
-keep class org.mozilla.javascript.** { *; }
-dontwarn org.mozilla.javascript.**

# Jsoup
-keep class org.jsoup.** { *; }

# Protobuf & Jackson/Json
-keepclassmembers class * {
    @com.fasterxml.jackson.annotation.* *;
}
```

## 6. Verification and Contract Testing Strategy
- **FakeMusicSource**: Full deterministic in-memory mock supplying pre-populated artist, album, track, search, and audio stream data for all unit tests (T1) and Robolectric Compose tests (T2).
- **NewPipeMusicSource**: Real network implementation executing against YouTube Music.
- **Contract Tests**: Shared test suite `MusicSourceContractTest` runs against `FakeMusicSource` in standard JVM test suites, and against `NewPipeMusicSource` on live network via opt-in gradle flag `./gradlew test -PliveTests`.
